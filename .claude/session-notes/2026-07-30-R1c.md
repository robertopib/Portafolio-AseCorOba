### Content
**Status: done on preview (foundation)** — commit `c4e5e87`.

**KEY LOCKED FINDING:** `imageSizes` does **NOT** generate under `clientUploads`.
Traced in Payload v3.86 `packages/payload/src/uploads/generateFileData.ts`: on a
client-upload create, `req.file` is undefined and `shouldReupload()` is false, so it
returns at `if (!file) { return { data, files: [] } }` (~line 154) **before** the
sharp resize gate (~line 384). Server never gets the bytes → `sharp` never runs →
`sizes.thumbnail` stays null. Columns are created but empty. ⇒ thumbnail *generation*
is R1d, not a "backfill".
