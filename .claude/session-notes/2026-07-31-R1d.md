## R1d — Generate media thumbnails (sharp → R2) — 2026-07-31

### Context
`clientUploads` bypasses server sharp (R1c finding), so `sizes.thumbnail` was null.
R1d generates thumbnails ourselves for future uploads (hook) + the existing 42 (backfill).

### Content
**Status: done on preview** — commit `7381793`.

Built:
- `cms/src/lib/generateThumbnail.ts` — own S3Client (mirrors payload.config s3Storage);
  GetObject original → sharp 400px WebP q70 (aspect preserved) → PutObject as
  `{base}-{w}x{h}.webp` → returns `sizes.thumbnail`. Skips SVG/non-raster; failures log
  and return null (never breaks upload).
- `cms/src/collections/hooks/generate-media-thumbnail.ts` — Media `afterChange` hook;
  recursion-guarded (`context.skipThumbnailGeneration`), idempotent.
- `cms/src/scripts/backfill-thumbnails.ts` — `pnpm payload run`, dbGuard-protected,
  report to `/tmp/backfill-thumbnails-report.json`.
- `api/[...slug]/route.ts` — `maxDuration = 60`. `@aws-sdk/client-s3` promoted to a
  direct cms dependency.

Verification: generate:types clean, tsc clean, `migrate:status` nothing new (reuses
R1c columns), build exit 0. **Backfill on dev: 43/43 processed, 0 failed; re-run
0/43 (idempotent).** Thumbnails serve 200 image/webp from media.ase-cor-oba.site,
aspect preserved. Pixel gate 0.000% (admin-only changes). Timing on 18.79 MB /24 MP:
sharp 227 ms + R2 up 665 ms; the ~26–50 s was local-broadband R2 *download* — on
Vercel (in-network with R2) it collapses to seconds, well within maxDuration=60.
